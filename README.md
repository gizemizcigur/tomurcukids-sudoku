# TomurcuKids Mini Sudoku — ilk oyun prototipi

- 4×4 sudoku, tek çözümlü yeni oyunlar üretir.
- Boş kareye, sonra alttaki resme dokunarak oynanır.

Bu paket bir **tarayıcı prototipidir**; App Store uygulaması değildir. Oyun akışını bilgisayarda test etmek içindir. iPhone/iPad'de kolay açılıp ana ekrana eklenebilmesi için dosyanın bir web adresine yayınlanması gerekir. Bağımsız iOS uygulaması ve dağıtımı sonraki aşamadır.
